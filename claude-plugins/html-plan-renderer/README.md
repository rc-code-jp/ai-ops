# HTML Plan Renderer for Claude Code

Claude Code の Plan Mode で作られる実行プランは標準では Markdown のため、長くなったり構造化されたプラン(目次・要点・ファイル変更一覧・検証手順など)を一目で把握するのが難しくなります。
このプラグインは、合意済みの実行プランを **読みやすい HTML ファイル** として `./plans/` 配下に書き出すスキルを提供します。

ブラウザで開くだけで、目次・章立て・要点ブロック・ファイル変更一覧・チェックリスト風の検証手順が視覚的に整理された状態でレビューできます。

## 含まれる skills

- `html-plan` — 合意済みの実行プランを HTML として `./plans/plan-YYYY-MM-DD-{slug}.html` に書き出すスキル。ユーザーが明示的に指示したターンのみ発動します。

## 使いどころ

- Plan Mode で出来上がったプランを後からブラウザで落ち着いてレビューしたい
- チームメンバーや非エンジニアにプラン内容を共有したい(HTML なら印刷も Web 共有も容易)
- 長大なプランで目次や章ナビゲーションが欲しい
- プラン内容を git 管理しつつ、人間に読みやすい形でも残したい

## 発動方法

このスキルは **ユーザー明示指示のみで発動** します。Plan Mode 終了時や、ユーザーが指示していないターンでは自動発動しません。

発動例:
- 「HTMLでプランを出して」
- 「html-plan でプランを書き出して」
- 「いまのプランを HTML ファイルにして」

## 出力例

```
./plans/
└── plan-2026-05-11-add-html-plan-skill.html
```

ファイル名規則: `plan-YYYY-MM-DD-{slug}.html`(同日衝突時は `-2`,`-3` を付与)。

## スタイル方針

- インライン CSS のみ、外部 CDN / 外部 JS 依存なし
- システムフォント(`system-ui`)、最大幅 760px、行間 1.7 で長文でも読みやすく
- `prefers-color-scheme` でダーク / ライト両対応
- `@media print` でナビ非表示、PDF 化にも適合
- JavaScript は埋め込まない(セキュリティと再現性のため)

## ローカルテスト

```bash
claude --plugin-dir ./claude-plugins/html-plan-renderer
```

読み込み後、合意済みのプランがある状態で「html-plan で HTML プランを出して」と指示すると、`./plans/` 配下に HTML が生成されます。

## 既知の制約

- JavaScript を使わないため、折りたたみやタブなどの動的 UI は提供しません(CSS のみで実装可能な範囲のレイアウトに留めます)。
- 出力先は固定で `./plans/`(リポジトリのルート相対)です。
- Mermaid やシンタックスハイライトのような外部ライブラリ依存機能は使いません。
