# Planning Facilitator for Claude Code

実装着手の前にユーザー側の理解度をきちんと揃えるためのスキル群です。

## 含まれる skills

- `rikai-implement` — 副作用のある操作の直前に発動し、実装方針を要点で提示したうえでユーザーの理解度をテストしてから実装に進むゲート。

## 使いどころ

- Claude が実装に走り出す前に、自分（指示者）が内容を本当に理解しているか確認したい
- 「OK」だけで通過させず、要約や境界条件で理解の解像度を揃えたい
- 計画レビューが終わったあと、実装フェーズへの橋渡しに確実なゲートを置きたい

## ローカルテスト

```bash
claude --plugin-dir ./claude-plugins/planning-facilitator
```

読み込み後は、副作用のある操作の直前に `rikai-implement` が自動で発動します。明示的にスキップしたいときはユーザーが「説明不要」「すぐ実装」「rikai スキップ」等とそのターンで指示してください。
