# irasutoya-docs

フリー素材サイト[「いらすとや」](https://www.irasutoya.com)の画像を検索・取得し、SVG や絵文字の代わりに**いらすとやのイラストで統一されたスライド・ドキュメント**を HTML として出力する Claude Code プラグインです。

## 特徴

- **いらすとや画像の自動検索・取得**: いらすとやは Blogger 製サイトのため、Blogger 公開フィード API を検索エンジンとして利用（HTML スクレイピング不要・標準ライブラリのみの Python スクリプト同梱）
- **概念→キーワード変換ガイド**: 「スケーラビリティ」「承認フロー」のような抽象概念を、いらすとやでヒットする具体的な日本語キーワードに変換する語彙集を同梱
- **利用規約ガードレール**: 商用 1 制作物あたり素材 20 点までの無料枠をスキルが自動カウント。禁止用途・再配布にあたる依頼は拒否
- **2 つの出力形式**: 16:9 スライド（1 スライド 1 ページで PDF 印刷可）と A4 ドキュメント（表紙・目次・章ごと改ページ）
- **テンプレート同梱方式**: CSS はテンプレートに固定。JS なし・CDN なし。画像はローカル保存されるためオフラインでも閲覧可
- **コンテキスト節約**: HTML の組み立てはサブエージェントに委任し、生成 HTML 全文を親会話履歴に残さない
- **明示的呼び出しのみ**: ユーザーが「いらすとやで」と指示したターンに限って発動

## 使い方

```
この提案内容をいらすとやでスライドにして
この手順書をいらすとや資料（ドキュメント）にして
irasutoya-doc で障害対応フローの説明スライドを作って
```

出力先はユーザー指定が最優先。指定が無ければ `./docs/irasutoya-YYYY-MM-DD-{slug}/` に `index.html` と `images/` が保存されます。同日同 slug は上書きされるため、修正→再生成を繰り返せます。

PDF にする場合は、生成された HTML をブラウザで開き、印刷（Cmd+P / Ctrl+P）から「PDF に保存」してください（スライドは 1 枚 1 ページで出力されます）。

## 仕組み

```
① 構成設計（スライド/章 + 各所のビジュアルコンセプト、ユニーク画像 ≦20 点）
② scripts/irasutoya_search.py search <キーワード...>   ← Blogger フィード API（JSON）
③ 検索結果のタイトルを見て画像を選定
④ scripts/irasutoya_search.py download <URL...> --dir images/
⑤ サブエージェントがテンプレート + 部品カタログで index.html を組み立て
```

ネットワーク接続先は `www.irasutoya.com` と `blogger.googleusercontent.com` のみです。リクエスト間には自動で待機（既定 1 秒）が入ります。

## 構成

```
irasutoya-docs/
├── .claude-plugin/plugin.json
└── skills/irasutoya-doc/
    ├── SKILL.md                      # 発動条件・手順・規約ガードレール
    ├── scripts/
    │   └── irasutoya_search.py       # 検索・ダウンロード CLI（Python 標準ライブラリのみ）
    └── references/
        ├── keyword-guide.md          # 概念→いらすとやキーワード変換ガイド
        ├── slide-template.html       # 16:9 スライドテンプレート
        ├── doc-template.html         # A4 ドキュメントテンプレート
        └── components.md             # 本文に使える部品のカタログ
```

## いらすとや利用規約について

本プラグインは[いらすとやの利用規約](https://www.irasutoya.com/p/terms.html)の範囲内での利用を前提としています。

- 商用・非商用とも無料で利用可能（クレジット表記不要）
- **商用利用は 1 つの制作物につき素材 20 点まで無料**（21 点以上は有償対応）。スキルはユニーク画像数をカウントし、超過しそうな場合は警告します
- 素材主体の再配布・販売、公序良俗に反する利用は禁止

規約は変更される可能性があるため、重要な用途では原文を確認してください。
