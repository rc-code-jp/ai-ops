# いらすとや検索キーワードガイド

いらすとやの検索（Blogger フィード API）は、**記事タイトルとラベルへの単純一致**である。
抽象語や複合語はヒットしないため、資料中の概念を「いらすとやに存在しそうな具体的な日本語の名詞」に言い換えてから検索する。

## 基本ルール

1. **日本語で検索する**。英語はほぼヒットしない（例: `server` ✕ → `サーバー` ○）
2. **1〜2 語の短い名詞**にする。文や修飾語の連結はヒット率が下がる
3. **抽象概念は「人の動作・感情・モノ」に翻訳**する
4. ヒットしなければ **より一般的な語に段階的に緩める**（例: `API連携` → `連携` → `握手` → `パソコン`）
5. 検索結果の **タイトルを読んで文脈に合うものを選ぶ**。同名で複数バリエーション（男性/女性、笑顔/真剣 等）があることが多い

## 検索のコツ

- **人物のバリエーション**: 多くの題材で `〜する人`（例: `パソコンを使う人`）、性別・年齢違い、`真剣` / `笑顔` などの表情違いがある。スライドのトーンに合わせて選ぶ
- **表情・状態の指定**: タイトル末尾の `（笑顔）` `（真剣）` `（男性）` などで絞り込める
- **職業もの**: `白衣` `作業服` `スーツ` など服装での言い換えも有効
- **季節・行事**: 日付ネタ（正月、ハロウィン等）は豊富。資料のアクセントに使える
- **`--max` は 8 程度**で十分。多すぎると選定コンテキストを圧迫する

## ヒットしない場合のフォールバック

1. 同義語・類義語に置き換える（`ミーティング` → `会議`）
2. カタカナ ⇔ 漢字を切り替える（`パソコン` ⇔ `コンピューター`）
3. 概念の「絵になる瞬間」を想像して動作語にする（`承認フロー` → `印鑑`）
4. それでも無ければ、その箇所は画像なし（テキストのみ）とする。**いらすとや以外の画像や絵文字・SVG アイコンで代替しない**（このスキルの趣旨に反する）
