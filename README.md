## スキルインストール

スクリプトを実行すると、このリポジトリ内のスキル一覧が表示されます。上下キーで選択し、Enter で決定すると、実行する `npx skills add ...` のコマンドを表示してからインストールを開始します。

```bash
bash scripts/install_skill.sh
```

ドライラン:

```bash
bash scripts/install_skill.sh --dry-run
```
