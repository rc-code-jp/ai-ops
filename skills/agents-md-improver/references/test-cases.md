# agents-md-improver テスト設計

## 発火テスト

### 発火すべき依頼（5 件）

1. 「CLAUDE.md をレビューして」
2. 「AGENTS.md を改善して」
3. 「指示ファイルが長すぎるので整理したい」
4. 「エージェントの動きがブレるので指示を見直して」
5. 「md の指示を最適化して」

### 発火すべきでない依頼（5 件）

1. 「このスキルをレビューして」（SKILL.md が対象 → codex-skill-improver）
2. 「サブエージェント定義を見直して」（codex-subagent-improver）
3. 「README.md を書いて」（一般的なドキュメント作成）
4. 「コードレビューして」（コードレビュー）
5. 「PR をレビューして」（PR レビュー）

## 機能テスト

### 正常系

1. **曖昧な指示の検出**: 「丁寧に対応する」「必要に応じて確認する」を含む CLAUDE.md を入力し、観点 2（指示の具体性）で問題が検出されること
2. **肥大化ファイルのスキル分解提案**: 300 行超の CLAUDE.md を入力し、観点 9（スキル分解可能性）で分離提案が出ること
3. **総合評価の出力**: レビュー結果が A〜D の評価付きで、指定のレポート形式で出力されること

### エラー系

1. **対象外ファイル**: SKILL.md を渡された場合に対象外であることを報告すること
2. **ファイル未検出**: CLAUDE.md / AGENTS.md が存在しないリポジトリで適切にエラー報告すること

## ベースライン比較

| 指標 | スキルなし | スキルあり |
|------|-----------|-----------|
| レビュー観点の網羅性 | レビュアー依存でばらつく | 10 観点を毎回チェック |
| 出力形式の一貫性 | 自由記述でばらつく | 総合評価 + 重要度別の統一形式 |
| 往復メッセージ数 | 3〜5（観点の確認往復） | 1〜2（レポート出力 + 承認） |
