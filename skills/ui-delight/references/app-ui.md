# App UI

アプリUIやプロダクトUIで使う詳細ルールです。

## 基本方針

アプリUIでは、装飾過多ではなく抑制を優先します。

- calm surface hierarchy
- strong typography and spacing
- few colors
- dense but readable information
- minimal chrome
- cards only when the card is the interaction

## 画面構成

構成は、主作業領域、ナビゲーション、補助コンテキスト、強いアクセント1色を基本に組みます。

- primary workspace
- navigation
- secondary context or inspector
- one clear accent for action or state

## 避けるもの

- 理由の薄いカード分割
- 情報量を減らさず装飾だけ増やすこと
- 不要な色数
- 視線を奪う浮遊要素
- 機能より見た目を優先して操作性を落とすこと
