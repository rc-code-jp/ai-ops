# Landing Pages

ランディングページやブランドサイトで使う詳細ルールです。

## ファーストビュー

- 最初の画面をポスターとして扱う。文書の冒頭や情報一覧にしない
- ファーストビューの要素は基本的に、ブランド、見出し、短い補足文、CTA グループ、支配的な画像だけに絞る
- 統計、イベント一覧、住所、補助販促、メタ情報列、複数の宣伝ブロックをファーストビューに入れない

## ブランドと階層

- ブランド名またはプロダクト名を、ナビゲーション上の小要素ではなくヒーローレベルの信号にする
- どの見出しもブランド名より強くしない
- ナビを消したら別ブランドにも見えるなら、ブランド表現が弱すぎると判断する

## ヒーロー

- ブランド訴求のあるランディングページでは、ヒーローは原則フルブリードにする
- 差し込み画像、横並びの小さなヒーロー画像、丸角カード状のヒーロー、コラージュ、浮遊画像ブロックをデフォルトにしない
- 画像はプロダクト、場所、空気感、利用文脈を見せる主役である必要がある。抽象グラデーションだけを主ビジュアル扱いしない
- ヒーロー上に、浮いたラベル、バッジ、シール、情報チップ、説明ボックスを重ねない
- 画像を消しても成立するなら画像が弱い。ナビを消してブランドが消えるなら階層が弱い

## 標準構成

1. Hero: ブランドまたはプロダクト、約束、CTA、支配的なビジュアル
2. Support: 具体的な特徴、価値、証拠を1つ示す
3. Detail: 空気感、利用体験、ワークフロー、物語を深める
4. Final CTA: 行動に変換する

各セクションは1つの仕事だけを持ち、見出しも1つに絞ります。
何を伝えるセクションか一言で言えないなら、構造が崩れています。
