# Agents

Claude Code や Codex で使うエージェント定義ファイルです。

## インストール

推奨: リポジトリを clone していない環境でも、次のコマンドで一覧から選んでインストールできます。

```bash
bash <(curl -sL https://raw.githubusercontent.com/rc-code-jp/ai-ops/main/agents/install_agent.sh)
```

このリポジトリを clone 済みなら、次のようにローカルから実行できます。

```bash
bash agents/install_agent.sh
```
