# Multi-Agent Coordination

Claude の multi-agent coordination patterns に合わせて、Codex の複数 agent 運用を設計するためのプラグインです。

## 含まれる skills

- `multi-agent-coordination`

## 使いどころ

- Claude Code 利用者にも伝わる5分類で、Codex の複数 agent 運用を説明したい
- `Generator-verifier`、`Orchestrator-subagent`、`Agent teams`、`Message bus`、`Shared state` のどれを使うべきか判断したい
- Codex の subagent、custom agent、共有ストア、外部 queue への落とし込み方を整理したい
