# html-doc-renderer（Codex 版）

仕様書・設計書・計画資料・プロジェクト説明資料などのドキュメントを、**表紙・目次付きで PDF 印刷にも最適化された読みやすい HTML** として出力する Codex プラグインです。

Claude Code 版（`claude-plugins/html-doc-renderer/`）と同一のテンプレート・コンポーネントカタログを使用し、SKILL.md だけを Codex の流儀（built-in `worker` サブエージェント委任・段階的開示）に合わせています。

## 特徴

- **PDF / 印刷最適化**: 表紙が 1 ページ目、目次が 2 ページ目、章ごとに自動改ページ。`@page` でページ番号を出力（Chromium 131+）。表・図・コールアウトはページ境界で分断されない
- **テンプレート同梱方式**: CSS / スタイルは `assets/template.html` に固定。AI は毎回コンテンツだけを流し込むため、スタイルの揺れがない
- **視覚表現コンポーネント**: フロー図・タイムライン・簡易ガント・数値ハイライト・カードグリッドなどを純 HTML/CSS（JS なし・CDN なし）で同梱
- **フラットデザイン**: 影なし・罫線ベース・控えめな色数。ダークモード対応（印刷はライト固定）
- **コンテキスト節約**: HTML の組み立ては built-in `worker` サブエージェントに委任し、生成 HTML 全文を親会話履歴に残さない
- **明示的呼び出しのみ**: ユーザーが指示したターンに限って発動。自動発動しない

## 使い方

```
この仕様を html-doc で HTML にして
この計画資料を HTML ドキュメントにして
プロジェクト説明資料を HTML で ./share/ に出して
```

出力先はユーザー指定が最優先。指定が無ければ `./docs/doc-YYYY-MM-DD-{slug}.html` に保存されます。同日同 slug は上書きされるため、修正→再生成を繰り返せます。

PDF にする場合は、生成された HTML をブラウザで開き、印刷から「PDF に保存」してください。

## 構成

```
html-doc-renderer/
├── .codex-plugin/plugin.json
├── assets/
│   ├── template.html             # HTML 外枠 + 全コンポーネント CSS（印刷最適化込み）
│   └── components.md             # 本文に使える部品のカタログ
└── skills/html-doc/SKILL.md      # 発動条件・委任手順
```

## コンポーネント一覧（抜粋）

| カテゴリ | 部品 |
|---|---|
| 構造 | 章セクション（改ページ単位）/ 小節 / 段落 |
| コールアウト | 情報 / 注意 / 危険 / 完了条件 |
| 表 | データ表 / 改訂履歴表 |
| リスト | 番号付き手順 / チェックリスト / 用語定義 |
| 視覚表現 | 横・縦フロー図 / タイムライン / 簡易ガント / 数値ハイライト / カードグリッド / ステータスチップ |
| その他 | コードブロック / 図+キャプション / 改ページ制御 |

詳細は `assets/components.md` を参照してください。

## Claude 版との同期について

`assets/template.html` と `assets/components.md` は Claude 版 `claude-plugins/html-doc-renderer/skills/html-doc/references/` 配下と同一内容のコピーです。どちらかを変更した場合は、もう一方にも同じ変更を反映してください。
