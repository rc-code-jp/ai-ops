# HTML Plan Renderer for Codex

Codex で合意済みの実行プランを **読みやすい HTML ファイル** として `./plans/` 配下へ書き出すスキルを提供するプラグインです。

ブラウザで開くだけで、目次・章立て・要点ブロック・ファイル変更一覧・チェックリスト風の検証手順が視覚的に整理された状態でレビューできます。

## 含まれる skills

- `html-plan` — 合意済みの実行プランを HTML として `./plans/plan-YYYY-MM-DD-{slug}.html` に書き出すスキル。ユーザーが明示的に指示したターンのみ発動します。

## 動作モデル(サブエージェント委任型)

HTML の組み立て・書き出しは **Codex の built-in `worker` サブエージェント** に委任します。
親 Codex はプラン本文とメタ情報をサブエージェントに渡し、戻り値として受け取るのは **保存パスだけ** です。

```
[親 Codex] ──プラン本文 + メタ情報──► [built-in worker サブエージェント]
                                         assets/template.html を Read
                                         プレースホルダ置換
                                         ./plans/... へ Write
[親 Codex] ◄────保存パス(短文)───── [built-in worker サブエージェント]
```

これにより:

- 生成 HTML 全文(数 KB 〜 数十 KB)が Codex の会話履歴に残らない
- 反復的な再生成(質問→プラン修正→再 HTML 化)で会話コンテキストが累積しない
- 大規模リファクタの長大プランでもメイン推論を圧迫しない

## 使いどころ

- 合意済みの実行プランを後からブラウザで落ち着いてレビューしたい
- ユーザーが HTML を見ながら質問・確認・修正依頼を繰り返す前提のプランレビュー
- 大規模リファクタなど長大なプランで目次や章ナビゲーションが欲しい
- チームメンバーや非エンジニアにプラン内容を共有したい(HTML なら印刷も Web 共有も容易)
- プラン内容を git 管理しつつ、人間に読みやすい形でも残したい

## 発動方法

このスキルは **ユーザー明示指示のみで発動** します。プランを立てた直後やユーザーが指示していないターンでは自動発動しません。

発動例:

- 「HTML でプランを出して」
- 「html-plan でプランを書き出して」
- 「いまのプランを HTML ファイルにして」

## 出力例

```
./plans/
└── plan-2026-05-12-add-html-plan-skill.html
```

ファイル名規則: `plan-YYYY-MM-DD-{slug}.html`。
反復生成時(プラン修正→再 HTML 化)は **同日同 slug を上書き** します(履歴を増やしすぎないため)。明示的に「別ファイルで残して」と指示された場合のみ `-2`,`-3` を付与します。

## スタイル方針 / スキャナビリティ

人間はプラン全文を順に読むより、**冒頭で全体を掴み、必要な章だけを深く読む** のが普通です。
そのためテンプレートは次の工夫を入れています。

- **TL;DR バナー**: 「3 行で / 最大影響 / 必読箇所」を最上部に色付きで固定
- **メタチップ**: ⚠ 影響範囲 / ⏱ 推定時間 / 🔄 ロールバック容易度 をピル形状で即時表示
- **重要度バッジ**: 各章見出しに `必読 / 詳細 / 参考` バッジを付与
- **ファイル変更表**: パス・操作・**規模(S/M/L)**・**リスク(低/中/高、色分け)**・概要の 5 列
- **「ここを必ず読んでください」ブロック**: レビュー時の重点ポイントを赤マーカー付きで強調
- **Sticky 目次**: 左サイドバーに常時表示(スマホでは上部に折りたたみ)
- **`<details>` 折りたたみ**: ステップの詳細は折りたたみ可能で、スキャン時はタイトルだけ見える

加えて、基本方針として:

- インライン CSS のみ、外部 CDN / 外部 JS 依存なし
- システムフォント(`system-ui`)、本文は最大幅 760px、行間 1.7 で長文でも読みやすく
- `prefers-color-scheme` でダーク / ライト両対応
- `@media print` で目次・折りたたみを開いた状態に強制し PDF 化にも適合
- JavaScript は埋め込まない(セキュリティと再現性のため)

## インストール方法

このリポジトリの repo ローカル marketplace は `.agents/plugins/marketplace.json` です。marketplace 名は `ai-ops`、Codex 上の表示名は `AI Ops` です。

1. このリポジトリを Codex で開く。
2. Codex を再起動して、repo ローカル marketplace を読み込ませる。
3. CLI では `codex` を起動して `/plugins` を実行する。Codex app では Plugins を開く。
4. marketplace で `AI Ops` を選ぶ。
5. `HTML Plan Renderer` を開き、`Install plugin` を選ぶ。
6. 新しい thread で「いまのプランを HTML で出して」のように明示的に指示すると、`./plans/` 配下に HTML が生成される。

## 既知の制約

- JavaScript を使わないため、折りたたみやタブなどの動的 UI は提供しません(CSS のみで実装可能な範囲のレイアウトに留めます)。
- 出力先は固定で `./plans/`(リポジトリのルート相対)です。
- Mermaid やシンタックスハイライトのような外部ライブラリ依存機能は使いません。
- 初期版は **1 枚物の HTML** のみを出力します。章単位の分割出力はユーザーから明示要望が出た時点で追加する方針(早すぎる抽象化を避けるため)。
- 委任先は Codex の built-in `worker` サブエージェントを使います。Codex 環境で built-in agent の spawn が有効である必要があります。
