# Multi-Agent Deliberation

複数のサブエージェントによる独立分析と反証を、根拠に基づく判断へ統合するプラグインです。

## 含まれる skills

- `deliberate-with-agents`

## 使いどころ

- 分析や調査を反証付きで検討したい
- 設計案の隠れた前提や失敗条件を確認したい
- 変更してよいかを実装前に多角的に判断したい

`$deliberate-with-agents` を明示的に呼び出して使用します。

2体のサブエージェントが独立分析と1回の相互批評を行います。審議中は状態を変更せず、実装は別フェーズとして扱います。サブエージェントは親の権限を継承するため、技術的な読み取り専用が必要な場合は、呼び出す前に親タスクを読み取り専用に設定してください。
